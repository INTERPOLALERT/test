📍 100% FREE APIs (No Credit Card Required!)
───────────────────────────────────────────────────

1️⃣ GROQ API ⭐ RECOMMENDED - START HERE!
   🔗 Get API Key: https://console.groq.com/
   📚 Documentation: https://console.groq.com/docs
   💰 Free Tier: Extremely generous (14,400 req/day) - UNLIMITED!
   ⚡ Best For: Ultra-fast inference (< 1 second), general purpose
   📝 Setup:
   - Sign up (30 seconds, no credit card!)
   - API Keys → Create
   - Copy key: GROQ_API_KEY=gsk_xxx
   - Rate Limit: 14,400 requests/day (240/hour)

2️⃣ GOOGLE GEMINI API ⭐ GREAT FOR IMAGES
   🔗 Get API Key: https://makersuite.google.com/app/apikey
   📚 Documentation: https://ai.google.dev/docs
   💰 Free Tier: 60 requests/minute - COMPLETELY FREE!
   ⚡ Best For: Multi-modal (images, video), fast responses
   📝 Setup:
   - Go to Google AI Studio
   - Sign in with Google (no credit card!)
   - Click "Get API Key" → Create in new project
   - Copy key: GEMINI_API_KEY=AIzaSyxxx
   - Rate Limit: 60 requests/minute

3️⃣ DEEPSEEK CODER API
   🔗 Get API Key: https://platform.deepseek.com/
   📚 Documentation: https://platform.deepseek.com/api-docs
   💰 Free Tier: Free credits for new users
   ⚡ Best For: Code-specific tasks, coding assistance
   📝 Setup:
   - Register → API Management → Create Key
   - Copy key: DEEPSEEK_API_KEY=sk-xxx
   - Rate Limit: 100 requests/minute

4️⃣ OPENROUTER (Multi-Model Gateway)
   🔗 Get API Key: https://openrouter.ai/keys
   📚 Documentation: https://openrouter.ai/docs
   💰 Free Tier: Access to FREE models (Llama, Mistral, etc.)
   ⚡ Best For: Access to 100+ models through one API
   📝 Setup:
   - Sign in with Google → Keys → Create
   - Copy key: OPENROUTER_API_KEY=sk-or-xxx
   - Use free models: meta-llama/llama-3-8b-instruct:free
   - Rate Limit: 60 requests/minute

5️⃣ MISTRAL AI API
   🔗 Get API Key: https://console.mistral.ai/
   📚 Documentation: https://docs.mistral.ai/
   💰 Free Tier: €5 credit for new accounts (lasts long!)
   ⚡ Best For: European data compliance, fast models
   📝 Setup:
   - Create account → API Keys → Generate
   - Copy key: MISTRAL_API_KEY=xxx
   - Rate Limit: 60 requests/minute

───────────────────────────────────────────────────
🔧 QUICK SETUP INSTRUCTIONS (2 Minutes!)
───────────────────────────────────────────────────

MINIMUM REQUIREMENT: Get just ONE API key (we recommend Groq!)

1. Get Groq API key: https://console.groq.com/ (30 seconds!)
2. Copy .env.example to .env
3. Add your key: GROQ_API_KEY=gsk_your_key_here
4. Run startgpt.bat
5. Start generating websites!

RECOMMENDED: Get 2-3 API keys for redundancy
- Primary: Groq (fastest, most generous)
- Backup: Gemini (great for images)
- Extra: DeepSeek (best for code)

❓ TROUBLESHOOTING
───────────────────────────────────────────────────

Q: API key not working?
A: Check if you copied the full key including prefixes (gsk_, AIzaSy, etc.)

Q: Rate limit exceeded?
A: System will auto-switch to another API. Add more API keys for higher limits.

Q: All APIs failing?
A: Check internet connection and verify API keys in .env file.

Q: Slow generation?
A: Make sure Groq API is configured (fastest provider).

Q: "No API providers available"?
A: Add at least ONE API key to .env file.
