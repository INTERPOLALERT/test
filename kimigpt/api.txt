METHOD 1: IN-APP API MANAGEMENT (EASIEST!) ✨
────────────────────────────────────────────────

3. Click "⚙️ API Settings" button

────────────────────────────────────────────────
1. Get Groq API key: https://console.groq.com/ (30 seconds!)

3. Add your key: GROQ_API_KEY=gsk_your_key_here
4. Run startgpt.bat
5. Start generating websites!

❓ TROUBLESHOOTING
───────────────────────────────────────────────────

Q: API key not working?
A:
   1. Check if you copied the FULL key including prefix:
      - Groq: gsk_...
      - Gemini: AIzaSy...
      - Hugging Face: hf_...
      - Cohere: (no prefix)
   2. Use the "Test Connection" button in API Settings
   3. Check logs for error messages

Q: Rate limit exceeded?
A: System will auto-switch to another API. Add more API keys for
   higher combined limits:
   - 1 API = 14,400 req/day (Groq only)
   - 2 APIs = 14,400 + 86,400 = 101,000+ req/day
   - 4 APIs = 100,000+ requests/day combined!

Q: All APIs failing?
A:
   1. Check internet connection
   2. Verify API keys in API Settings page
   3. Click "Test Connection" for each API
   4. Check browser console for errors (F12)

Q: Slow generation?
A: Make sure Groq API is configured (fastest provider).
   Also add Cohere for backup speed.

Q: "No API providers available"?
A: Add at least ONE API key using the API Settings page.

Q: Can't find API Settings page?
A: Click the "⚙️ API Settings" button on the main dashboard,
   or go directly to: http://localhost:5000/api-settings

Q: API key saved but not working?
A:
   1. Check if .env file was created (should be in kimigpt folder)
   2. Restart the application (run startgpt.bat again)
   3. Keys should load automatically
